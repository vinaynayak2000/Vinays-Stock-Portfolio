# 📊 Vinay's Stock Portfolio

A personal **Indian stock portfolio tracking dashboard** designed to monitor investments, portfolio performance, P&L, allocation, and key portfolio metrics through a clean and interactive web interface.

🔗 **Live Dashboard:** [vinays-stock-portfolio.vercel.app](https://vinays-stock-portfolio.vercel.app/?utm_source=chatgpt.com)

🔗 **GitHub Repository:** [Vinays-Stock-Portfolio](https://github.com/vinaynayak2000/Vinays-Stock-Portfolio?utm_source=chatgpt.com)

---

## ✨ Features

### 📈 Portfolio Overview

* Track total portfolio value
* Monitor invested capital
* Track overall profit & loss
* Calculate portfolio returns
* View portfolio-level performance at a glance

### 💰 Stock Holdings

* View individual stock holdings
* Track quantity and investment value
* Monitor current market value
* Track profit/loss for each holding
* Compare individual stock performance

### 📊 Portfolio Analytics

* Portfolio allocation
* Stock-wise contribution
* Performance analysis
* Investment distribution
* Gain/loss visualization

### 🎨 Interactive Dashboard

* Modern and responsive UI
* Clean dashboard layout
* Interactive charts and visualizations
* Desktop and mobile-friendly design

## 🚀 Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/vinaynayak2000/Vinays-Stock-Portfolio.git
```

### 2. Navigate to the project

```bash
cd Vinays-Stock-Portfolio
```

### 3. Install dependencies

```bash
npm install
```

### 4. Start the development server

```bash
npm run dev
```

The application will then be available at the local development URL provided by Vite.

---

## 🏗️ Build for Production

Create a production build with:

```bash
npm run build
```

Preview the production build locally:

```bash
npm run preview
```
